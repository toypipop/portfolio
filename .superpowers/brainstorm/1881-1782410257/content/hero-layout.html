Design Notes

Key decisions embedded in this layout

GSAP Name glitch effect on load · ScrollTrigger fade-in per section · Vine SVG path draw on scroll
FONT Heading: Space Grotesk (bold, geometric) · Body/code: JetBrains Mono · Both free via Google Fonts
ROUTING React Router v6 · 5 pages: / /about /skills /projects /contact · Framer Motion page transition
FOG CSS radial-gradient overlay · Spore particles: lightweight canvas (50 particles max) · No Three.js
MOBILE Navbar collapses → hamburger at <768px · Hero text scales down · Cards single column
